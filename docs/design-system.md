# Design system
| Token | Value | Use |
|---|---|---|
| Forest green | `#173F32` | Brand, headings, primary buttons |
| Warm cream | `#F7F2E8` | Page background |
| Tea gold | `#C59A5B` | Accents, badges, CTA |
| Charcoal | `#252820` | Text and dark sections |

- Type: Fraunces (headings), Figtree (body)
- Glassmorphism: floating nav, cart drawer, search overlay, modals, toolbars (`css/glassmorphism.css`)
- Neumorphism: only on controls such as quantity selector and size buttons (`css/neumorphism.css`)
- Product cards stay clean and flat so the tea imagery leads
- Motion: one hero entrance, scroll reveals via GSAP, reduced-motion respected
